# Mula Group Repository

Start with `START_HERE_MULAGROUP.md` and `CODEX_WORKFLOW.md`.

This repository is organized as a pnpm + Turborepo monorepo with:

- `apps/portal`
- `apps/strategy`
- `apps/digital`
- `apps/commerce`
- `apps/industry`
- `apps/projects`
- `apps/lifestyle`
- shared packages in `packages/*`

Key commands:

- `corepack pnpm install`
- `corepack pnpm dev`
- `corepack pnpm dev:all`
- `corepack pnpm lint`
- `corepack pnpm typecheck`
- `corepack pnpm build`
