- one main portal: `mulagroup.eu`
- six pillar sites:
  - strategy
  - digital
  - commerce
  - industry
  - projects
  - lifestyle

The Projects pillar is responsible for:
- project concept design
- investment structure
- wellness and resort concepts
- premium spatial development logic
- experience-based business models
- project positioning
- multi-domain project architecture
- project growth pathways

This site is not a generic developer page, architecture portfolio or inspiration board.
It must feel like a **premium project-development platform** for ambitious ventures, concepts, spaces and investment-oriented initiatives.

## Main goal
Build the Projects pillar homepage / core pillar page using the shared foundation and the Projects blueprint.

The page must:
- position the Projects pillar as the place where vision becomes structured project logic,
- explain how concepts, spaces, experiences and business models connect,
- show project-development capabilities in a premium and investment-aware way,
- guide users toward the right entry point for project discovery,
- establish Mula Projects as a high-trust partner for ambitious initiatives.

The result should feel:
- premium
- spatially elegant
- structured
- conceptually strong
- business-aware
- calm
- serious and investment-ready rather than decorative

---

## Scope of work
Build the main Projects pillar page with the following sections:

### 1. Header / navigation
Create a pillar-specific navigation aligned with the ecosystem style.

Suggested navigation:
- Overview
- Services
- Project Types
- Process
- Contact

Include one primary CTA such as:
- `Discuss a project`

Navigation must feel connected to the shared Mula Group system.

---

### 2. Hero section
Build a Projects hero section that communicates:
- project concept development
- investment-oriented structure
- spaces and ventures
- premium, experience-aware project logic

Include:
- label / eyebrow
- headline
- subheadline
- 1–2 CTAs
- visual treatment aligned with the premium corporate-tech system

The hero should feel elegant, spatial and strategic, not like a flashy property promo.

---

### 3. Trust / intro section
Build a section that explains:
- why this is more than architecture or inspiration,
- why projects must connect concept, space and business logic,
- why large or premium initiatives need structure before execution,
- why the Projects pillar exists inside a wider ecosystem.

This section should reduce ambiguity and build project-development trust.

---

### 4. Services section
Build a premium services section for the Projects pillar.

It should include the core service areas from the Projects blueprint, such as:
- Project Concept Design
- Investment Structure Design
- Wellness & Resort Concepts
- Premium Space Development Logic
- Experience-Based Business Models
- Integrated Project Architecture

Each service block should:
- be concise,
- be conceptually clear,
- be business-relevant,
- avoid becoming abstract or fluffy.

---

### 5. Project types section
Build a dedicated section showing the kinds of project categories the pillar supports.

This section may include:
- wellness & spa
- resort & hospitality
- premium lifestyle spaces
- experience-led destinations
- mixed-use concepts
- investment-ready project pathways

The section should show that different types of projects require different structures and growth logic.

Do not make this section look like a developer listing or inspirational moodboard.

---

### 6. Who it’s for section
Build a section that helps users self-identify.

Use cases may include:
- investors and property owners
- entrepreneurs building new ventures
- wellness / hospitality concepts
- premium brands creating physical experiences
- multi-pillar ventures requiring a central concept

This section should help the right user feel recognized quickly.

---

### 7. Process section
Build the Projects process section.

Suggested structure:
- Explore
- Define
- Structure
- Prepare
- Expand

This section should communicate that Mula Projects works through project architecture, not just concept storytelling.

---

### 8. Offer formats section
Build a section presenting practical engagement formats, such as:
- Project Discovery Session
- Concept Blueprint
- Investment Readiness Path
- Premium Experience Design
- Integrated Project Architecture

This section should make it easy to understand how collaboration can start in a realistic way.

---

### 9. Differentiators section
Build a section showing why Mula Projects is different.

This should communicate:
- concept plus business logic
- connection between project thinking and real execution pathways
- ability to connect spaces, experience and growth structure
- relation to Strategy, Digital, Commerce, Industry and Lifestyle
- treatment of projects as evolving systems, not static concepts

Do not make this sound like generic development marketing copy.

---

### 10. Cross-pillar logic section
Build a section showing how Projects connects into the wider Mula Group ecosystem.

This section should explain that Projects often connects with:
- Strategy
- Digital
- Commerce
- Industry
- Lifestyle

The visual and content logic should make the ecosystem feel connected, premium and actionable.

---

### 11. FAQ section

- whether early-stage concepts are supported
- whether investor-facing structure can be supported
- whether Projects connects with digital and commercial planning
- whether the work is about architecture, business, or both
